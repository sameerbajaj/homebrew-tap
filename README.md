# Sameer Bajaj's Homebrew Tap

Official [Homebrew](https://brew.sh) tap for native macOS software created by [Sameer Bajaj](https://sameerbajaj.com).

Explore all tools, apps, and utilities at [sameerbajaj.com/tools](https://sameerbajaj.com/tools).

## How to Install

Add the tap:

```bash
brew tap sameerbajaj/tap
```

Install an application:

```bash
# Install MacYT
brew install --cask macyt

# Install EnhancedSkills
brew install --cask enhanced-skills

# Install Codex Accounts
brew install --cask codex-accounts

# Install agy-usage-stats
brew install --cask agy-usage-stats
```

Or install directly in a single command:

```bash
brew install --cask sameerbajaj/tap/macyt
brew install --cask sameerbajaj/tap/enhanced-skills
brew install --cask sameerbajaj/tap/codex-accounts
brew install --cask sameerbajaj/tap/agy-usage-stats
```
