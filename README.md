# Sameer Bajaj's Homebrew Tap

Official [Homebrew](https://brew.sh) tap for macOS software created by [Sameer Bajaj](https://sameerbajaj.com).

## How to Install

Add the tap:

```bash
brew tap sameerbajaj/tap
```

Install an application:

```bash
# Install MacYT
brew install --cask macyt

# Install EnhancedSkills
brew install --cask enhanced-skills
```

Or install directly in a single command:

```bash
brew install --cask sameerbajaj/tap/macyt
brew install --cask sameerbajaj/tap/enhanced-skills
```

## Available Casks

| Cask | Description | Homepage |
| :--- | :--- | :--- |
| **`macyt`** | Native macOS menu bar YouTube video and audio downloader powered by yt-dlp | [sameerbajaj.com/tools/macyt](https://sameerbajaj.com/tools/macyt) |
| **`enhanced-skills`** | Native macOS skill manager and validator for Claude Code and Codex | [sameerbajaj.com/tools/enhanced-skills](https://sameerbajaj.com/tools/enhanced-skills) |
